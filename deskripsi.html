1. Nama Proyek

Website Promosi Produk Pangan Lokal Indonesia

2. Latar Belakang

Indonesia memiliki beragam produk pangan lokal yang menjadi bagian dari kekayaan budaya dan potensi ekonomi masyarakat. Namun, tidak semua produk pangan lokal dikenal secara luas, terutama oleh generasi muda.

Perkembangan teknologi informasi dan media digital dapat dimanfaatkan sebagai sarana untuk mengenalkan produk pangan lokal dengan cara yang lebih menarik dan mudah diakses.

Oleh karena itu, dibuat sebuah website yang berfungsi sebagai media informasi dan promosi produk pangan lokal Indonesia. Website ini menyajikan informasi produk melalui teks, gambar, artikel, dan galeri.

Website ini dibuat sebagai proyek berbasis teknologi informasi dengan menerapkan HTML, CSS, dan JavaScript tanpa menggunakan sistem database.

3. Tujuan Pembuatan

  1. Mengenalkan berbagai produk pangan lokal Indonesia kepada masyarakat.
  2. Menyediakan informasi mengenai produk pangan lokal dalam bentuk digital.
  3. Mempromosikan produk melalui teks dan media visual yang menarik.
  4. Menerapkan kemampuan dasar HTML, CSS, dan JavaScript dalam sebuah proyek nyata.
  5. Membuat website yang dapat diakses melalui perangkat komputer maupun smartphone.
  6. Menerapkan konsep desain antarmuka yang sederhana, informatif, dan mudah digunakan.
  7. Mendukung penggunaan bahasa Indonesia dan English.

4. Konsep Website

Website dirancang sebagai media informasi dan promosi, bukan marketplace atau sistem transaksi.

Setiap produk memiliki informasi: nama, kategori, asal daerah, gambar (URL), deskripsi, dan keunikan.

Data tidak dimasukkan melalui dashboard atau database. Data disiapkan langsung dalam kode JavaScript sehingga website dapat berjalan dengan struktur yang sederhana.

5. Target Pengguna

  • Pelajar
  • Masyarakat umum
  • Pengunjung yang ingin mengenal pangan lokal Indonesia
  • Pengguna yang mencari informasi mengenai produk pangan lokal

6. Fitur Website

6.1 Beranda

Halaman utama website dengan hero, statistik, pengenalan, infografis scroll, produk pilihan, artikel terbaru, dan CTA.

6.2 Detail Produk

Menampilkan 20 produk pangan lokal dalam bentuk card. Setiap card berisi foto, nama, kategori, dan asal daerah. Klik card untuk membuka informasi lengkap (deskripsi & keunikan) secara expand.

6.3 Search

Pencarian produk berdasarkan nama, berjalan murni menggunakan JavaScript.

6.4 Filter Kategori

Menyaring produk berdasarkan kategori: Semua, Makanan, Camilan, Minuman, dan Pangan Fermentasi.

6.5 Artikel

Enam artikel informatif mengenai pangan lokal, ditampilkan sebagai card dan dibuka melalui modal popup.

6.6 Galeri

Kumpulan gambar dari URL eksternal dengan tampilan grid responsif dan pratinjau lightbox.

6.7 Responsif

Website dapat menyesuaikan ukuran layar: smartphone, tablet, laptop, dan desktop.

6.8 Dark Mode

Pilihan tampilan Light Mode dan Dark Mode melalui tombol pada navbar, dengan transisi warna halus.

6.9 Animasi UI

Animasi sederhana: hover card, transisi tombol, munculnya konten saat scroll, smooth scrolling, dan transisi dark mode.

6.10 Pilihan Bahasa

Dua pilihan bahasa: Indonesia dan English. Sistem bahasa menggunakan data terjemahan di dalam JavaScript.

7. Teknologi yang Digunakan

  • HTML — struktur halaman website.
  • CSS — tampilan, layout, responsive, dark mode, dan animasi.
  • JavaScript — data produk, search, filter, expand, modal, dark mode, bahasa, dan interaksi pengguna.

8. Sistem Data

Website tidak menggunakan database. Data produk, artikel, dan galeri disimpan langsung dalam file js/data.js, sedangkan data terjemahan disimpan di js/language.js.

Jika ingin menambahkan atau mengubah data, perubahan dilakukan langsung pada file kode tersebut.

11. Desain Antarmuka

Konsep desain website menggunakan pendekatan Modern Nusantara:

  • Sederhana, modern, bersih, dan profesional
  • Fokus pada foto produk dan tipografi
  • Konsisten warna & tipografi
  • Tanpa efek glow, neon, atau elemen futuristik
  • Tanpa ikon dekoratif
  • Mengutamakan keterbacaan informasi dan kemudahan navigasi

Palet warna: Hijau Tua, Cream, Terracotta, Kuning Rempah, Putih.

Tipografi: Poppins (heading) dan Inter (body).

12. Keamanan

Karena website tidak menggunakan akun pengguna dan tidak menyimpan data pribadi, sistem keamanan kompleks seperti autentikasi dan database tidak diperlukan.

  • Tidak memasukkan password atau API key ke dalam kode.
  • Tidak menampilkan data pribadi yang tidak diperlukan.
  • Menggunakan file dan aset yang aman.
  • Melakukan validasi sederhana pada input pencarian.
  • Menjaga struktur kode agar mudah diperiksa dan dikembangkan.

13. Kelebihan Konsep Website

  • Lebih mudah dibuat.
  • Tidak memerlukan konfigurasi database.
  • Tidak memerlukan server database.
  • Cocok untuk proyek sekolah.
  • Lebih mudah dipahami oleh pemula.
  • Data sudah tersedia ketika website dijalankan.
  • Dapat dikembangkan secara bertahap.
  • Kebutuhan teknis relatif sederhana.

14. Batasan Sistem

  1. Tidak terdapat fitur login pengguna.
  2. Tidak terdapat dashboard admin.
  3. Tidak terdapat fitur menambahkan produk melalui website.
  4. Tidak terdapat transaksi online.
  5. Tidak terdapat sistem pembayaran.
  6. Data produk harus diubah melalui kode.
  7. Website berfungsi sebagai media informasi dan promosi, bukan marketplace.

15. Kesimpulan

Website Promosi Produk Pangan Lokal Indonesia merupakan proyek pengembangan website sederhana yang bertujuan untuk mengenalkan dan mempromosikan produk pangan lokal melalui media digital.

Website menggunakan HTML, CSS, dan JavaScript tanpa database. Data produk, artikel, dan informasi lainnya disiapkan langsung dalam kode sehingga sistem lebih sederhana dan sesuai untuk proyek sekolah.

Meskipun sederhana, website memiliki fitur interaktif lengkap: beranda infografis, detail produk expand, search, filter kategori, artikel modal, galeri, responsive design, dark mode, animasi UI, dan pilihan bahasa Indonesia–English.
